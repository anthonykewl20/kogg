# Domain Docs

This repository uses a multi-context domain layout.

Before working, read root `CONTEXT-MAP.md`, then the relevant package
`CONTEXT.md` files and applicable ADRs.

- System-wide ADRs: `docs/adr/`
- Package context glossary: `packages/<package>/CONTEXT.md`
- Package ADRs: `packages/<package>/docs/adr/`

Use glossary terms consistently and explicitly flag proposals that contradict
an existing ADR. Domain files are created lazily when terminology or durable
architectural decisions are resolved.
