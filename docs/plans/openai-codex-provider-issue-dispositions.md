# OpenAI Codex provider issue dispositions

[ADR 0002](../adr/0002-do-not-implement-codex-subscription-provider.md)
preserves Qwen Code as the Agent Runtime and records that no supported public
contract currently permits the proposed ChatGPT-subscription Model Provider.
The issues below therefore have a **not planned** disposition, without claiming
that their requested deliverables were produced.

| Issue                                                                                                                   | Disposition evidence                                                                                                                                                                                              |
| ----------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Define the secure Provider Session lifecycle](https://github.com/anthonykewl20/kogg/issues/7)                          | ADR 0002 adds no provider identity, credential namespace, token lifecycle, entitlement catalog, or persisted state. A Codex Provider Session therefore has no supported subject whose lifecycle can be specified. |
| [Prototype the terminal authentication and model-selection experience](https://github.com/anthonykewl20/kogg/issues/8)  | ADR 0002 adds no Codex terminal authentication, Provider Session, entitlement catalog, or inference surface. A prototype of those unsupported surfaces cannot establish an accepted v1 experience.                |
| [Define the cross-platform authentication threat model](https://github.com/anthonykewl20/kogg/issues/9)                 | ADR 0002 adds no Codex authentication flow, credential lifecycle, storage namespace, or platform-support surface. A threat model for those absent components has no supported system boundary to analyze.         |
| [Define the hermetic verification and live smoke-test release gate](https://github.com/anthonykewl20/kogg/issues/10)    | ADR 0002 adds no Codex provider implementation, migration, or live integration. A provider-specific release gate has no supported artifact or account flow to qualify.                                            |
| [Approve the implementation-ready OpenAI Codex Provider specification](https://github.com/anthonykewl20/kogg/issues/11) | ADR 0002 deliberately leaves every provider architecture dimension absent and invalidates dependent delivery work. No implementation-ready provider specification exists to approve under this decision.          |
| [Complete Codex streaming, tools, usage, and optional capabilities](https://github.com/anthonykewl20/kogg/issues/18)    | ADR 0002 adds no Codex inference adapter, capability mapping, or supported direct-inference contract. No streaming, tool, usage, optional-capability, or fake-inference seam exists to implement or test.         |
| [Enforce authentication security, privacy, and failure contracts](https://github.com/anthonykewl20/kogg/issues/19)      | ADR 0002 adds no Codex provider authentication, inference, credential, or telemetry boundary. No real provider seam exists at which to enforce or test the requested security, privacy, and failure contracts.    |
| [Publish and validate the public provider release](https://github.com/anthonykewl20/kogg/issues/20)                     | ADR 0002 adds no provider implementation or releasable artifact and invalidates release work. There is no supported public behavior, smoke evidence, documentation set, or rollback path to publish.              |
